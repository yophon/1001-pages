巨字页脚，第四批

这一批换的是“质感”和“性格”：笔迹、机械、材质、光影、液体、天气、表情、拼贴。用法和前几页一样，顶栏可以换品牌名，离开屏幕就暂停。

你的系统开了“减少动画”：自动播放的部分会停掉，鼠标触发的效果保留。

01

签名描线

滚到这里时，大字像被一支笔逐个描出轮廓，描完再填上墨色，一个字接一个字，像在签名。

做法是 SVG 文字的描边动画：把描边设成一段很长的虚线，再把虚线的起点从末尾挪到开头。每个字是一个 tspan，各自延迟一点开始。

02

机场翻牌

像车站的翻牌显示屏，每一格翻过几个随机字符后停在目标字上。每隔几秒换一条：品牌名、现在几点、一句招呼。点一下翻牌屏可以立刻换下一条。

每一格由四片组成：上下两片静止的半格，加上一片往下翻的上半格、一片翻下来的下半格，翻页用 Web Animations 控制先后。

03

镭射闪卡

大字像一张全息镭射卡，鼠标移动时彩虹反光跟着流动，还有一块高光跟着光标走，整块字随之微微倾斜。

纯 CSS：彩虹条纹、高光、噪点、银色底四层背景叠在一起，用混合模式融合后，裁剪成文字的形状。鼠标位置只改几个 CSS 变量。

04

光源投影

鼠标是一盏悬在纸面上方的灯，字是立在纸上的厚纸片，影子永远背着灯的方向拉长；离灯越远，影子越长。鼠标不在时，灯会自己绕着转，像日晷。

字和纸几乎同色，全靠影子把字形托出来。影子是把每个字的剪影沿投影方向连贴 28 次、每次很淡叠出来的，所以离字越远越淡。

05

字里装水

每个字是装着半杯水的玻璃：鼠标左右移动，水面跟着倾斜；手划过水面会起波纹，点一下会溅起来；快速滚动页面，水会晃。时不时还会冒一串气泡。

水面是一排互相牵连的弹簧，每帧算一遍波动；整片水画在离屏画布上，再用文字的形状裁剪。

06

积雪

雪落在笔画的顶上会停住，越积越厚，还会顺着边缘滑下来堆成斜坡。鼠标划过可以把雪扫掉，扫起来的雪会重新飘落。积得太多时，最上层的雪会慢慢化掉。

画面被分成 3px 的小格子，字所在的格子是实心的；每片雪往下落，下面堵住了就试着往左下、右下滑，都堵住了就停在原地，变成积雪的一格。

07

会眨眼的字

字母的空心里长出了眼睛，眼珠跟着鼠标转，时不时眨一下；快速滚动页面时眼珠会晃，像玩具上的活动眼。

眼睛的位置是自动找的，和第三批“钻进字母里”用的是同一个办法：找出所有空心，在每个空心里离笔画最远的点放一只眼睛。中文也行，比如“回”有两只、“日”有两只。品牌名里没有空心时，就在字中间贴一对。

08

剪报拼贴

每个字像是从不同的报纸杂志上剪下来的：字体、底色、角度都不一样，边缘是剪刀剪出的毛边。鼠标碰到哪个字，那个字就换一张。

字体只用 Windows 自带的，中文从微软雅黑、楷体、宋体、仿宋、黑体里挑；毛边是随机缩进的多边形裁剪。

✓

四页合起来

  • 基础六种：裁切、幕布、渐隐、手电筒、升起、透图。
  • 进阶八种：可变字体、跑马灯、橡皮筋、点阵、物理、粒子、液体、实时数据。
  • 第三批：立体、钻洞、光栅、天空、钢琴、终端、足迹、旗帜。
  • 这一批：签名、翻牌、镭射、投影、装水、积雪、眼睛、剪报。
