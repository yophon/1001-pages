巨字页脚，进阶八种

和基础版一样：每节上半部分是正文，往下滚是页脚，顶栏可以换品牌名。这一版每个效果都在离开屏幕时暂停，同时在屏幕上的最多两三个，不会一起占着 CPU 和显卡。

源码都在这个 HTML 里，每个效果是一段独立的代码，用注释标好了编号。

你的系统开了“减少动画”：自动播放的部分（波浪、跑马灯、闪烁、雨滴、下落过程）会停掉，鼠标触发的效果保留。

01

可变字体“磁场”

鼠标附近的字母变粗、变宽，其余字母同时变细、变窄，整行宽度始终不变，像被磁铁挤开。鼠标不在的时候，粗细会像波浪一样慢慢流过去。

字体是 Roboto Flex（OFL 开源授权，字重 100–1000、字宽 25–151），只取了拉丁字符，约 250KB，放在本地 lib 目录。最初用的是 Windows 自带的 Bahnschrift，结果 Chrome 对系统里的可变字体不做插值，只会在几个预设字重之间跳。中文不在这个字体里，用描边加粗加横向缩放来模拟，变化是连续的，但只是近似。

02

速度跑马灯

品牌名横向无限循环。页面滚得越快，跑得越快，还会顺着方向倾斜；往回滚，方向也跟着反过来。在这一节附近上下快速滚动试试。

03

橡皮筋拉伸

已经到底了还继续往下滚，大字就被往上拉长，松手后弹回去，还会晃一下。这个效果只在“滚到底”的时候成立，所以下面放了一个模拟窗口：在窗口里滚到底，再继续滚。整页最底下的真页脚也是同样的效果。

触控板、鼠标滚轮、触屏都可以。macOS 和 iOS 自带的回弹会叠在上面，真上线要在那边再调手感。

模拟页面：在这里滚到底，再继续往下滚
04

ASCII 点阵屏

logo 用字符画出来，像琥珀色的老终端。光标附近的字符会乱翻、变亮，空白处会露出点阵网格，移开后慢慢恢复。没人动的时候也会零星闪几个字。

每帧要画两三千个格子，所以先把字符预渲染成一张图集，再一块块贴上去，不逐个调用 fillText。

05

物理掉落

滚到这里时，品牌字母和一堆标签从上面掉下来，堆在底部。可以用鼠标拎起来甩，也可以把它们垒起来。

物理引擎是 Matter.js 0.20.0，已经放在本地 lib 目录里。手机上只有按住某个元素才会拖拽，按在空白处还是正常滚动页面，避免和滚动抢手势。

lib/matter.min.js 没加载成功，这一节显示不了。

06

粒子 logo

大字由几千个粒子组成。鼠标划过像风吹沙，划得越快吹得越远，移开后粒子会飞回原位重新拼好。每次滚进屏幕都会从散开的状态重新拼一次。

粒子数按屏幕大小自动调整，上限 8000 左右；画布按设备像素比绘制，高分屏也不糊。

07

WebGL 液体扭曲

页脚像一层水面，鼠标划过会留下涟漪，大字跟着扭曲，边缘有 RGB 色散。没人动的时候会偶尔落下一滴“雨”。

用的是原生 WebGL2，没有引入 three.js：一个着色器模拟水波的高度场，另一个按高度场的坡度去偏移文字纹理。显卡不支持时退回普通大字。

你的浏览器或显卡不支持这里用到的 WebGL2 浮点纹理，下面显示的是退回后的普通大字。

08

带实时数据的页脚

不靠特效，靠真实数据：上海此刻的时间和天气、系统状态、今年已经过去多少、你在本页停留了多久。

天气接的是 Open-Meteo，系统状态接的是 GitHub 的公开状态页，只用来演示接法。两个接口失败时都有兜底文字，页脚不会空一块；天气结果缓存 20 分钟。

✓

这一版额外做的几件事

  • 离开屏幕就暂停。所有动画共用一个 requestAnimationFrame 循环，只跑当前在屏幕上的效果。
  • 尊重“减少动画”。开了这个系统设置时，自动播放的部分都会停，鼠标触发的保留。
  • 都有兜底。WebGL 不支持、物理引擎没加载、接口失败，都退回普通大字或文字。

最底下这个页脚就是 03 的橡皮筋：滚到底以后再继续往下滚。
