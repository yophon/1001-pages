巨字页脚，六种低成本做法

每一节上半部分是“正文”，往下滚就是那一种页脚。顶栏可以换成你自己的品牌名（中文也行），所有大字会自动重新铺满。效果本身都只靠 CSS，04 和 06 各加了几行 JS；页面里另外那段脚本只是按品牌名算字号。

01

铺满整行，底边裁掉一截

字比容器略宽、底部沉到页脚外面，被边缘切断的那一刀就是冲击力的来源。下面两个按钮对比一下“颜色只比背景亮一点”和“纯白硬顶”。

看代码
footer     { overflow: hidden; }
.mark-wrap { container-type: inline-size; }
.mark {
  font-size: 22cqw;         /* 按字数调到刚好铺满 */
  font-weight: 900;
  letter-spacing: -0.05em;
  line-height: 0.8;
  margin-bottom: -0.15em;   /* 往下沉，字底被裁掉 */
  white-space: nowrap;
  color: #26262c;           /* 只比背景 #111114 亮一点 */
}
02

幕布揭开

正文盖在页脚上面，往下滚时像幕布一样拉开，露出一直垫在底下的页脚。这一节的正文故意做成一整屏高，继续往下滚就能看到。

前提：正文要有背景色，页脚不能高过一屏。圆角和阴影是可选的，加上之后“幕布”的感觉更明显。

看代码
main {
  position: relative; z-index: 1;
  background: var(--bg);
  border-radius: 0 0 28px 28px;           /* 可选 */
  box-shadow: 0 30px 60px rgb(0 0 0 / .5); /* 可选 */
}
footer { position: sticky; bottom: 0; }
03

往下渐隐，或者空心描边

比硬裁切柔和，适合偏安静、偏杂志感的品牌。这一节顺便换成了衬线斜体，可以看看换个字体气质差多少。

看代码
/* 渐隐 */
.mark { mask-image: linear-gradient(to bottom, #000 15%, transparent 90%); }

/* 描边 */
.mark { color: transparent; -webkit-text-stroke: 1.5px rgb(207 230 216 / .55); }
04

鼠标手电筒

字平时是暗的，鼠标经过的地方被照亮。把鼠标移到下面的大字上试试（手机上按住拖动）。

看代码
.mark > span {
  color: transparent;
  background: radial-gradient(circle 18cqw at var(--x, 50%) var(--y, 50%), #fff, #1e1e22 70%);
  -webkit-background-clip: text;
  background-clip: text;
}

const lit = document.querySelector('.mark > span');
footer.addEventListener('pointermove', e => {
  const r = lit.getBoundingClientRect();
  lit.style.setProperty('--x', e.clientX - r.left + 'px');
  lit.style.setProperty('--y', e.clientY - r.top + 'px');
});
05

滚到时从底下升起

CSS 原生的滚动驱动动画，不写 JS。时间线挂在 footer 上而不是大字本身：大字底部被裁掉了一截，它自己永远“进不完”视口，挂在它身上的话，页面滚到底时动画会停在半路。

你的浏览器不支持滚动驱动动画，这里显示的是静态的最终效果（这也正是它的降级方式）。

你的系统开了“减少动画”，这一节显示静态效果。Windows 里在“设置 → 辅助功能 → 视觉效果 → 动画效果”。

看代码
@keyframes rise { from { transform: translateY(45%); opacity: 0; } }
footer { view-timeline: --foot block; }
@media (prefers-reduced-motion: no-preference) {
  .mark {
    animation: rise linear both;
    animation-timeline: --foot;            /* 必须写在 animation 后面 */
    animation-range: entry 30% entry 100%;
  }
}
06

字里透出照片

文字当窗口，后面放团队照、产品图或者渐变，一张图就让页脚有了内容。默认是纯 CSS 渐变，可以换成你自己的照片试试（只在本地预览，不会上传）。

看代码
.mark > span {
  background: url(photo.jpg) center / cover;
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}
✓

通用要点

  • 颜色和背景只差一点。让它当纹理，别用纯白大字硬顶。01 的两个按钮就是这个对比。
  • 字要少。品牌名太长就只放缩写或首字。中文两三个字铺满一行也很有冲击力，顶栏输进去看看。
  • 中文别为几个字加载整套字体。中文字体动辄几 MB，把这几个字导出成 SVG，或者只抽出这几个字做字体子集。
  • 用 cqw 而不是 vw。vw 在 Windows 上会把滚动条宽度也算进去，“铺满”时会多出一截被裁掉。
  • 纯装饰就加 aria-hidden="true"。页脚通常已经有正常的 logo 和文字，读屏软件不用再读一遍巨型重复字。

页面最底下这个是 01 + 05 的组合：低对比、底边裁切、滚到底时升起。
