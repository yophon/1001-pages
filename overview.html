标签怎么看

  • 轻：纯 CSS 或几十行脚本，几乎没有性能和兼容风险，可以直接上线。
  • 中：Canvas 2D 动画，正式用之前要照顾尺寸变化、离屏暂停和“减少动画”设置；演示页里这些都做了，但离产品级还要再打磨。
  • 重：实时模拟、WebGL、物理引擎或成千上万的元素，适合活动页和作品集；放在日常官网上要掂量低端手机的耗电和发热。
  • 声音：浏览器要求先点一下页面才允许出声，所有带声音的效果都只在点过之后才响。
